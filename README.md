# Campus Food Ordering System

## Project Overview
The Campus Food Ordering System is an Agile-based project designed to help students browse campus food items, search the menu, check prices and availability, and place orders easily.

## Sprint 1 Goal
To enable students to search campus food items and view relevant menu details.

## Key Features
- Food menu search by keyword
- Category-based filtering
- Display food name and price
- Show food availability
- Display a message when no matching item is found

## Technologies and Tools
- GitHub for version control and collaboration
- Agile Scrum for sprint planning
- Test cases for quality assurance

## Team
This project is created as a group activity for Agile Software Development.
