# Campus Food Ordering System – Menu Search

## User Story
As a student, I want to search campus food items by keyword so that I can quickly find the food I want.

## Acceptance Criteria
1. Students can search for food items by name.
2. Search should work regardless of uppercase or lowercase letters.
3. Students can filter food items by category.
4. Each result should display the food name, price, category, and availability.
5. If no matching food item is found, the system should display a clear message.
6. Out-of-stock food items should be marked as unavailable.

## Test Cases
- TC-1: Search for "Masala Dosa" and check matching results.
- TC-2: Search using lowercase letters and verify the results.
- TC-3: Filter food items by category.
- TC-4: Search for a nonexistent item and check the message.
- TC-5: Check that out-of-stock items are marked unavailable.

## Definition of Done
- All acceptance criteria are checked.
- Test cases are executed.
- Identified defects are recorded and fixed.
- A team member reviews the changes before merging.
